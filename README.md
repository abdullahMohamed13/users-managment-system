# Survey Land

A CRUD operation project, built during an internship in [@AfaaqWare](https://github.com/AfaaqWare), mentored by [@eslam-mohamedl](https://github.com/eslam-mohamedl)

<br />

# How To Run The Client (Frontend)
1. `cd client/`
2. `npm install`
3. `npm run dev`

# How To Run The Server (Backend)

1. `cd server/`
2. `npm install`
3. `node server.js`


⚠️ Backend is forked from: https://github.com/eslam-mohamedl/Json-Server-Auth
